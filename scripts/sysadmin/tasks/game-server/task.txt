Please deploy our multiplayer game server, Tiny Arena, on it. The code is in ~/game-server.tar.gz on the server (Node.js, see its README). Players' browsers must reach it at ws://{ip}/play, on port 80 through nginx. The game server has to run as its own unprivileged user, start at boot and restart by itself if it crashes, and it must not be reachable from outside except through nginx.
