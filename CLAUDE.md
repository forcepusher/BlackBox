# Notes for AI agents working on Sloperator
- `README.md` is for people: short and plain. Keep implementation details, measurements and the
  story of a change out of it; add to it only what a user needs to know to use Sloperator.
- `docs/notes.md` holds how each part works, why, and what was measured. Read the section you need
  before changing a feature, and update it when a behaviour changes.
- `CHANGELOG.md` follows Keep a Changelog: every change a user would notice gets a short line under
  `[Unreleased]` (Added, Changed, Fixed, Removed), in the same commit.
