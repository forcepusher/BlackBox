# Notes for AI agents working on BlackBox
- `README.md` is for people: short and plain. Keep implementation details, measurements and the
  story of a change out of it; add to it only what a user needs to know to use BlackBox.
- `docs/notes.md` holds how each part works, why, and what was measured. Read the section you need
  before changing a feature, and update it when a behaviour changes.
